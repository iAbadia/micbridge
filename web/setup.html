Enable trusted HTTPS

This installs this desktop's local certificate authority on your iPhone. It allows Safari to trust certificates issued by this desktop. Install only the certificate from your own Micbridge desktop.

  1. Compare the certificate fingerprint below with the desktop's certificate setup panel.
  2. Tap Download iPhone profile, then Allow the download.
  3. Open Settings → General → VPN & Device Management. Select the downloaded Micbridge profile and install it.
  4. Open Settings → General → About → Certificate Trust Settings. Enable full trust for the Micbridge certificate.
  5. Return to the desktop's HTTPS phone link. In Safari, choose Share → Add to Home Screen, or bookmark the full link.
