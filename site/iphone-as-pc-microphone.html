MICBRIDGE · Updated October 11, 2026

Use your iPhone as a Windows PC microphone.

Your iPhone can send microphone audio to your Windows PC over Wi-Fi, using Safari instead of a separate phone app. Micbridge receives the audio and sends it to a virtual microphone.

Download for WindowsHow it works

Before you start

  • A Windows x64 PC and an iPhone with Safari.
  • Both devices on the same reachable local network. Guest Wi-Fi can prevent devices from connecting.
  • Micbridge’s Windows installer, including optional VB-CABLE setup.
  • Headphones for monitoring, to avoid feedback.

1. Install the desktop app and virtual microphone

Download the Windows setup executable from Micbridge’s GitHub release. Leave VB-CABLE setup selected if you need the driver, complete the official VB-Audio installer and restart Windows. Micbridge reuses an existing base VB-CABLE installation.

The driver is Microsoft-signed; Micbridge’s own installer is unsigned. Download only from the project’s GitHub releases. VB-CABLE retains its separate license terms.

2. Trust your desktop’s local HTTPS certificate

Start Micbridge and choose First-time iPhone setup. Follow the desktop instructions to install the certificate profile on your iPhone, then enable full trust in iOS under Settings → General → About → Certificate Trust Settings. Installing a profile and enabling trust are separate steps. Trust only a certificate generated by a desktop you control.

Safari requires trusted HTTPS before it can capture the microphone. The setup guide explains the local certificate and troubleshooting.

3. Pair once and start your phone microphone

Open the phone link displayed by Micbridge. It normally looks like https://YOUR-DESKTOP-IP:8443/phone. Enter the six-digit desktop pairing code, tap Start microphone and allow Safari microphone access.

You can use Safari’s Add to Home Screen to save the phone page. Pairing is stored in the browser rather than in the URL. Reserve your desktop’s IP address in your router so the bookmark keeps working. Clearing website data or changing the address can require pairing again.

4. Send the audio to your Windows app

Click Enable Micbridge microphone on the desktop. In your meeting or recording app, choose Micbridge Microphone (VB-Audio Virtual Cable) as the microphone. An existing cable may retain the name CABLE Output (VB-Audio Virtual Cable).

Windows calls the playback side CABLE Input and the recording side CABLE Output. Micbridge sends to Input; the receiving app listens to Output. A moving meter inside Micbridge confirms phone reception. A moving meter in the receiving app confirms the complete route.

If the sound is quiet or stops

  • Low volume: increase Micbridge’s gain gradually while checking the receiving app’s meter. Reduce gain if the sound distorts.
  • No sound in the receiving app: check that it selected the VB-CABLE recording endpoint, rather than your physical microphone or another virtual device.
  • Stops when the phone locks: keep Safari or the home-screen web app visible and the screen awake. Background microphone capture is not reliable.
  • Phone cannot connect: check the displayed desktop address, network isolation, firewall access and certificate trust.

What has been tested?

The Windows installation and iPhone-to-virtual-microphone path have been confirmed on the maintainer’s PC. Automated checks also cover application behavior, driver installation and a 48 kHz audio roundtrip through VB-CABLE. This does not establish compatibility with every Windows PC or conferencing app.
